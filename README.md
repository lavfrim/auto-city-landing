# Auto City Landing Template

A lightweight, responsive landing page template for car-related businesses.

## Structure

- `index.html` - semantic page sections and content blocks
- `style.css` - visual theme and responsive layout
- `script.js` - mobile menu behavior and dynamic footer year

## Quick Start

Open `index.html` directly in a browser, or run a local static server:

```bash
cd /Users/Aliaksandr_Lazarau/LA/Projects/Auto-city/repos/auto-city-landing
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## What to Customize

- Brand name and text content in `index.html`
- Colors in `:root` CSS variables in `style.css`
- Call-to-action links and contact data in `index.html`
